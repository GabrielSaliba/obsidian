# Obsidian Vault

My [Obsidian](https://obsidian.md) vault, backed up and synced through GitHub.

## Structure

- `.obsidian/` — Obsidian app config (plugins, themes, hotkeys, etc.)
- `attachments/` — images, PDFs, and other files embedded in notes
- `books/` — notes and tracking related to books I'm reading
- `templates/` — note templates used inside Obsidian
- Top-level `.md` files — individual notes (games, learning tracks, projects, etc.)
- `.canvas` files — Obsidian Canvas boards
- `.base` files — Obsidian Bases views

## Syncing

Automated this with the [Obsidian Git plugin](https://github.com/denolehov/obsidian-git), which can auto-commit and push/pull on a schedule or on vault changes.
