## <span style="color:rgb(112, 48, 160)">Decisions</span>

- Vitest `4.1.10` is the approved exact unit-test runner for the Node.js `24.19.0` baseline.
- Unit tests are colocated and use `*.unit.test.ts`; application integration tests use `*.integration.test.ts`; provider contract tests use `*.contract.test.ts`.
- Shared test setup remains under root `test/`, while PostgreSQL, migration, RLS, authorization, and concurrency tests remain under `supabase/tests/`.
- Node is the default environment. Browser-like packages are deferred until a real DOM test requires a focused reviewed task.
- `pnpm test` is the stable unit-test gate handed to RPRT-4. RPRT-4 owns the GitHub Actions workflow and clean-checkout CI evidence.
- Unit tests never load `.env.local`, inherit Supabase credentials, or call real external services.

## <span style="color:rgb(192, 0, 0)">Issues</span>

- The test-only `server-only` alias permits server module unit tests but does not prove a negative Client Component import. The Next.js production build remains the current application-graph boundary check.
