## <span style="color:rgb(112, 48, 160)">Decisions</span>

- Split the administrator membership boundary into a small prerequisite issue and PR before RPRT-52.
- Use `service_role` as the M1 database trust boundary for worker commands. PostgreSQL generates the lease owner and lease token. RPRT-55 later protects scheduler HTTP requests.
- Test public RPC behavior, exact grants, RLS, constraints, and real races with pgTAP and controlled test-only `dblink` sessions.
- Use versioned database policy resolution and copy the complete RPRT-43 policy into each immutable outbox job snapshot.
- Use append-only records for provider-call reservations, provider-call results, replay authorizations, replay consumption, domain transitions, and dead-letter alerts.
- Keep provider adapters, generated database types, shared staging promotion, and production changes outside RPRT-52.

## <span style="color:rgb(192, 0, 0)">Issues</span>

- The repository currently has only the migration harness. No application tables, RLS policies, domain functions, or shared database-test helpers exist.
- RPRT-52 and RPRT-47 have a dependency cycle around `admin_users` and protected replay authorization.
- New public tables can inherit non-CRUD privileges. Every migration must revoke complete direct access before granting narrow RPC execution.
- Real concurrency tests need committed remote-session fixtures because another `dblink` session cannot see rows inside the outer rollback transaction.

## <span style="color:rgb(255, 192, 0)">Questions and Blockers</span>

- The RPRT-52 implementation plan requires final approval before Linear or repository changes begin.
- The new administrator-membership prerequisite must be created, implemented, reviewed, and merged before RPRT-52 moves to In Progress.
- Shared staging migration promotion remains outside this work and requires a separate explicit request.

## <span style="color:rgb(0, 112, 192)">Next Work</span>

- Create and refine the administrator-membership prerequisite under RPRT-3.
- Implement `admin_users` and the approved `public.is_admin()` contract with default-deny RLS and pgTAP authorization tests.
- Open the prerequisite PR into `dev` and wait for required human review and merge.
- Start RPRT-52 from updated `dev` and implement five red-green slices: immutable evidence, policy-based enqueue, worker claim and provider-call reservation, completion and dead-letter behavior, and administrator-protected replay.
- Run focused pgTAP tests during each slice, then run the complete local database and application gates.
