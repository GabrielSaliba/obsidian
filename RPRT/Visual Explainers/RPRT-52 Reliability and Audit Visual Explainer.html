What changed

Before this PR, provider work had no complete durable execution contract. After this PR, the database owns identity, policy, leases, call budgets, outcomes, alerts, and replay proof.

Core guarantee

One job. One immutable history. No budget reset.

Every provider call is reserved before dispatch and counted for the full lifetime of the original job. Retry and replay keep the same job, business key, payload version, policy snapshot, request fingerprint, counters, and transition history.

Reliability architecture

Commands enter through narrow RPCs. PostgreSQL serializes ownership, reserves each call, and writes evidence in the same transaction as every accepted state change.

Intake and durable identity
Domain command or webhook Stable IDs only. No secret or raw provider payload is stored.
Enqueue / record RPC Validate exact payload shape and global business key.

Claim batch FOR UPDATE SKIP LOCKED creates one bounded lease.
Reserve provider call Verify lease, fingerprint, automatic/replay/lifetime ceilings.
Dispatch outside database History is already reserved, so a lost response still remains counted.
Complete Store success once and make completed terminal.
Reschedule Retry safe work with bounded equal jitter and the same fingerprint.

Job lifecycle and replay

The normal lane is automatic and bounded. The replay lane starts only from dead letter and requires authenticated administrator proof.

05

Security boundary

Tables are evidence stores, not public APIs. All mutation enters through narrow functions with exact role grants, fixed empty search paths, row locks, and database-owned time.

Default-deny tables RLS enabled. Direct privileges revoked from public, anon, authenticated, and service role.
Narrow RPC surface Security-definer functions expose only approved commands and validate actor contracts.
Immutable evidence Update and delete triggers reject changes to events, transitions, calls, results, and replay proof.
Relational invariants Unique and composite foreign keys bind job, ordinal, lease, proof, consumption, and call history.
